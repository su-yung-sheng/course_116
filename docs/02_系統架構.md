**原則同 course_115**：兩學期資料夾結構一樣，差別只在 `config.js` 與 `content/`；`shared/` 只有一份，用 `../shared/xxx.js` 引用，沒有副本就不會漂移。
**內容與引擎分離**：改教什麼 → `private/…/content/*.js` 再 `node tools/build.mjs`；改版型或規則 → `shared/`。公開的 `content/*.js` 是建置產物，裡面沒有明碼答案。
各單元頁面只剩「載入內容＋呼叫引擎」幾行，例如：

```js
CARDGAME.mount({ app: '#app', levels: NET_LEVELS, mod: 'network' });
PYAPP.mount({ root: '#pyapp', levels: PY_LEVELS, mod: 'python', title, kicker, subtitle, finale, ref: 'pyref.html' });
SHEET.mount({ app: '#app', levels: SHEET_LEVELS, mod: 'sheet', ref: 'sheetref.html' });
LABKIT.mount({ sections: SECTIONS, mod: 'arduino' });
```

## 進度：`window.STORE`（本機版）

所有頁面只透過這組 API 讀寫進度：

```js
STORE.me()                                   // { cls:'901', seat:'05', name } 或 null
STORE.login(cls, seat, name) / logout()
STORE.level('python', 'P3')                  // { stars, score, tries, at, code }
STORE.saveLevel('python', 'P3', { stars, score, code })   // 星星只會變多（取最佳）
STORE.moduleStars('python') / moduleDone('python')
STORE.draft(key, value)                      // 編輯器草稿
STORE.exportJSON() / importJSON(text)        // 換電腦時帶著走
```

資料形狀刻意做成和 115 的 Firestore 文件一樣：

```
{學期}-progress/{學號} = { modules: { python: { levels: { P3: { stars: 3, score: 100, … } } } } }
```

### ⚠️ 本機版的限制

- 進度存在「這台電腦的這個瀏覽器」—— **電腦教室有還原卡的話，關機就清掉**
- 學生按 F12 可以改自己的星星 —— 本機版的星星是**學習回饋**，不是成績
- 沒有教師端

### 正式上課前：接回 115 的後端（第二階段）

只重寫 `shared/store.js`，**API 名稱不變，各單元頁面一行都不用改**：

1. 從 course_115 搬 `auth.js`、`guard.js`、`sso.js`、`firestore.rules`（學校 Google 帳號登入、`isOwner(sid)`）
2. `STORE.me()` 改讀 `AUTH`；`saveLevel()` 改成 Firestore `merge` 寫入 `11601-progress/{學號}`
3. `firestore.rules` 補上各模組的欄位（116-1：`digital` `python` `platform` `arduino`；116-2：`media` `network` `data` `sheet` `python` `arduino`）

5. 搬 `teacher.html`：Python 那一格可以直接看 `record.code`（最後一次送出的程式）
6. 名冊 `roster` 沿用（同一批學生）；學期鎖日期照 `semester.js`

## 依序開放

只有 Python（116-1 單元二、116-2 密碼特務）是依序開放（上一關 ≥ 2⭐ 才開下一關），判斷只看 `STORE` 的星數。
備課時要看全部關卡：`config.js` 設 `OPEN_ALL_UNITS: true` **並且一定要設 `OPEN_ALL_UNTIL` 到期日**，過期自動失效；開著的時候闖關地圖會掛橘色橫幅。

## 本機預覽

不要直接雙擊 HTML（`file://` 下 Web Worker 會被瀏覽器擋，Python 引擎起不來）。在 repo 根目錄：

```
python -m http.server 8116
```

開 `http://localhost:8116/`。
