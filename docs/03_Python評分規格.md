Python 和 Scratch 不同：文字程式可以**真的執行**，對錯是客觀的，不需要 AI 判讀。

## 執行流程

```
python.html ──► pyrunner.js ──postMessage──► pyworker.js（Web Worker 裡的 Pyodide）
                  │  3 秒沒回應 → terminate() 砍掉重開（while True 也收得掉）
                  └► 輸出超過 20,000 字 → TooMuchOutput（無窮 print）
```

- **input() 用「重播法」**：每次執行都先給好一串輸入；用完了回報 `need`，畫面問學生，再**從頭重跑一次**。
  `random` 每次重跑用同一個種子，所以重播結果一致。好處是不需要 SharedArrayBuffer（GitHub Pages 設不了那個標頭）。
- **time.sleep() 不會真的等**，只記下來；試跑時畫面每遇到一次 sleep 停 0.4 秒做動畫。
- 每次執行同時用 `ast` 分析程式結構（for／while／if 鏈長度／and／呼叫了哪些函式／用了哪些運算子）。

### checks（每組測資的判定，全部成立才算過）

比對前先**全形轉半形、去掉所有空白、轉小寫** —— 學生的句子可以不一樣，重點講到就好。

| 寫法 | 意思 | 看哪裡 |
|---|---|---|
| `{ line: 'Hello, World!' }` | 有一行完全相同 | print＋提示字 |
| `{ has: '免購票' }` | 找得到 | print＋提示字 |
| `{ not: '不及格' }` | 找不到 | print＋提示字 |
| `{ word: 'KHOOR' }` | 前後不緊貼英文字母的完整字（分大小寫） | **只看 print** |
| `{ order: ['太大','太小','答對'] }` | 依序出現 | print＋提示字 |
| `{ count: '錯誤', min: 3 }`（也可 `max`、`eq`） | 出現次數 | print＋提示字 |
| `{ num: 18.95, tol: 0.05 }` | 有一個數字在誤差內 | **只看 print** |
| `{ nums: [333, 1] }` | 數字依序出現 | **只看 print** |
| `{ nums: [3,2,1], tail: true }` | 最後幾個數字剛好是這些 | **只看 print** |

> 「提示字」會算進去，是因為課本的猜數字把「太大，請重猜：」寫在 `input()` 的提示裡。
> 數字類的檢查不看提示字，免得「請輸入 3 個數字」裡的 3 被算進去。
> 使用者打的輸入**不會**算進去（不然輸入 15、輸出沒有 15 也會過）。
> 輸出英文字母的關卡（密碼特務）用 `word`：提示字「請輸入 A～Z」裡的 A、Z 不會誤判。

### req（3⭐ 的結構要求）

`'路徑 比較 數字'`，路徑對應 `ast` 分析結果：

`for`、`while`、`if`、`elif`、`else`、`and`、`or`、`not`、`branches`（最長 if 鏈的分支數）、
`calls.print`、`calls.input`、`calls.int`、`calls.range`…、`binops.FloorDiv`、`binops.Mod`、`binops.Pow`、`binops.Div`…、`lines`

例：`'calls.print<=3'`（不准一行一行寫死）、`'branches>=4'`（if＋elif＋elif＋else）

## 寫測資的三個原則

1. **至少一組隱藏測資考邊界值** —— 不然寫死答案、`>` 和 `>=` 搞錯都會過
2. **檢查關鍵字，不要檢查整句** —— 「請購買：兒童票」「兒童票」都要算對
3. **會互相包含的字要加 `not`** —— 「及格」會命中「不及格」、「全票」要確認沒有同時印出「兒童票」

## 錯誤翻譯機（`PYRUN.explain`）

程式出錯時，學生看到的不是英文訊息，而是四段：

1. **標題**：第幾行、什麼問題（例：「第 2 行：這一行最後少了冒號 :」）
2. **你的程式 → 可以改成**：直接拿學生自己那一行，紅色標出有問題的地方、綠色標出要加或要換的字
3. **範例對照**：「❌ 常見的錯誤寫法」和「✅ 正確的寫法」並排，用課本會出現的程式當例子
4. **為什麼**：一兩句說明；最下面才收著 Python 的英文原始訊息

能從學生的程式推出改法的，一律給「可以改成」—— 看自己的程式比看別人的範例好懂：

| 錯誤 | 學生看到的標題 | 自動改法 |
|---|---|---|
| 全形符號 | 🔤 有全形符號「（」 | 引號外的全形換成半形（引號裡的中文標點保留） |
| 少冒號 | ❗ 這一行最後少了冒號 : | 行尾補「:」 |
| 該縮排沒縮排 | ↹ 這一行應該往右縮排 | 前面補 4 格 |
| 不該縮排 | ↹ 這一行不應該縮排 | 拿掉前面的空白 |
| 引號沒成對 | ❗ 引號沒有成對 | 補上同一種引號 |
| 括號沒關 | ❗ 括號沒有關起來 | 行尾補「)」；錯誤出現在下一行時，會指回真正出錯的上一行 |
| 多右括號 | ❗ 多了一個右括號 ) | 刪掉最後一個「)」 |
| if 裡用 = | ❗ 比較「是否相等」要用 == | = 換成 == |
| 少逗號 | ❗ 可能少了逗號 , | 在文字和變數之間補「, 」 |
| else if | ❗ Python 要寫 elif | 換成 elif |
| 指令拼錯（esle、whlie…） | ❗「esle」拼錯了 | 換成正確拼法 |
| print 沒括號 | ❗ print 後面要加小括號 | 補上 ( ) |
| 大小寫錯（Print） | 🔍 電腦不認識「Print」—— 是不是要寫「print」？ | 換成 print |
| int 遇到小數 | 🔢 int( ) 遇到了小數 | int( 換成 float( |

推不出改法的（變數還沒建立、文字＋數字、文字比大小、除以 0、停不下來的迴圈、測資輸入不夠），只給範例對照。
全部 22 種情況在 `tests/test_errors.mjs` 裡逐一驗證。

編輯器另外會**即時**提醒引號外面的全形符號（課本 2-1 特別提醒的語法地雷）。
