## 三、單元二：進入 Python 的世界（第 2 章）

故事線 **「九年級畢旅籌備處」**：用 Python 幫全班處理畢業旅行的大小事。每一關都對照 Scratch 積木（學生七、八年級學過）。

| # | 任務 | 概念 | 課本對照 | 3⭐ 結構要求 |
|---|---|---|---|---|
| P1 | 👋 哈囉，旅伴！ | `print()` | 概念1 文字輸出 | 兩個 print |
| P2 | 📝 畢旅報名表 | `input()`、變數 | **任務1 自我介紹** | 兩個 input |
| P3 | 💰 旅費分攤 | `int()`、`//`、`%` | 型態轉換、算術運算子 | int×2、`//`、`%` |
| P4 | ⚖️ 健康檢查 BMI | `float()`、運算順序 | **任務2 計算 BMI** | float×2、`/` |
| P5 | 🎢 雲霄飛車身高檢查 | 關係運算子、if／else | 選擇結構 | if＋else |
| P6 | 🎫 自動購票機 | if／elif／else | **任務3 自動購票機** | 四個分支一條鏈 |
| P7 | 🚀 極速飛車雙重關卡 | `and`／`or` | 邏輯運算子 | 用 and |
| P8 | 🚌 遊覽車發車倒數 | `for`、`range()` | 計次迴圈、倒數計時挑戰 | for＋range、print ≤ 3 |
| P9 | 🔐 置物櫃密碼鎖 | `while` | 條件迴圈 | while |
| P10 | 🎲 魔王關：猜數字 | while＋if 綜合 | **任務4 猜數字** | while＋if |

每一關的組成：情境 → 任務說明 → 範例執行畫面 → Scratch 對照 → 三段提示（一段比一段具體，**不給完整答案**）→ 編輯器 → 試跑 → 送出評分 → 延伸挑戰（2⭐ 後出現，不計星）。

**計星**（評分細節見 `03_Python評分規格.md`）

| 星 | 條件 |
|---|---|
| 1⭐ | 程式跑得動，至少過 1 組測資 |
| 2⭐ | 全部測資（含**隱藏測資**）通過 → **開下一關** |
| 3⭐ | 2⭐ ＋ 符合這一關的程式結構要求 |

> 隱藏測資專考**邊界值**（剛好 120 公分、剛好 65 歲…），學生只看得到「過／沒過」和一句提醒。
> 這是運算思維裡「測試與除錯」最具體的一環：把寫死答案、條件順序錯的程式擋在 2⭐ 之前。

### 4. 🎬 廣告工作站（不計星，記錄完成）

流程（2026-09-26 定案）：**決定主題 → 三句文案 → 拍攝重點 → 配樂 → 剪輯**

⭐ **單元核心：「好好用 AI」**。創意發想、文案、句型、鏡頭、配樂建議都可以請 AI 協助，重點是教學生正確使用 AI。工作站最上方固定顯示**五守則**：
① 先自己想，再問 AI　② 說清楚再問（主角、對象、特色、語氣、限制）　③ AI 給草稿，我做決定（記下改了什麼）　④ 檢查再用（會說錯、會誇大，拍不出來就不用）　⑤ 保護自己、誠實標示（不給人臉姓名學校；寫 AI 使用聲明）

每一步都有「🤖 AI 可以幫忙／🙋 要自己決定」說明與可一鍵複製的提示詞（自動帶入前面步驟的內容）：
W1 主角點子、看照片找特色（A1 感知） → W2 提示詞 A 發想、B 檢查 → W3 鏡頭建議 → W4 配樂風格與搜尋關鍵字 → W5 依同儕回饋的修改建議。
W3～W5 另有「📝 AI 建議紀錄」：貼上 AI 的建議就必須寫「採用／修改了什麼」；W5 的 AI 使用聲明依這些紀錄預先勾好，學生再確認。

| 步驟 | 網站做什麼 | 完成條件 |
|---|---|---|
| W1 🎯 決定主題 | 拍主角照片（選填，縮成小圖存進學習紀錄；提醒不要拍到人臉、名牌）→ 「看照片找特色」提示詞給 AI → 貼上 AI 回答 → 自己決定 **3 個看得見的特色**，圈出 **1 個核心特色**；觀眾、感受 | 主角、3 特色、核心特色、大家通常覺得它、觀眾 |
| W2 ✍️ 三句文案 | 先寫下**自己想的一句**（會放進提示詞），30 秒只用三句：**開場句**（0–3 秒，問句／反差）、**特色句**（8–18 秒，說出核心特色）、**收尾標語**（25–30 秒，≤ 12 字）。提示詞 A（發想，每種 3 個選項，自動帶入 W1 的特色）→ 選三句（字數計數、誇大用詞提醒）→ 提示詞 B（請 AI 檢查誇大、順不順、口語化，只給建議）→ 自己修改 | AI 工具、三句字數、我改了什麼 |
| W3 🎞️ 拍攝重點 | 五個時段色帶＋每段出現哪一句；逐鏡填時段、內容、**拍出哪個特色**、角度、秒數；可列印 → 實拍檢核 | 8～12 鏡、每時段 ≥ 1、**核心特色 ≥ 2 鏡、三個特色都有拍到**、有遠景和特寫、每鏡 2～4 秒、總長 26～34 秒；實拍檢核（挑戰以外）全勾 |
| W4 🎵 配樂 | 依 W1 的感受推薦風格；曲名、來源、作者／網址、授權（「不確定」會擋）；轉折對準第幾秒；配樂檢核 | 曲名、出處、授權確定、對拍秒數、檢核全勾 |
| W5 ✂️ 剪輯 | 剪輯檢核（三句放對時段、對拍、標語停 2 秒、1080p .mp4）→ 同儕試看三題 → 修正（可請 AI 依回饋給建議）→ **AI 使用聲明**（找點子或特色／文案／鏡頭建議／配樂建議／修改建議／畫面生成／沒有使用，依紀錄預先勾好）→ 作品說明卡 PNG | 長度 25～35 秒、檢核全勾、試看、修正說明、AI 聲明 |

**三句文案為什麼這樣設計**：三句剛好對上 30 秒的「抓注意 → 呈現特色 → 留下記憶」；特色句一定用 W1 的核心特色，所以 W3 可以直接「依特色決定拍攝重點」。AI 在 W1、W2 各用兩次（找特色；發想＋檢查），每次都是「AI 給草稿，學生做決定」，並留下修改紀錄。
