# 04 設計系統：讓整個網站看起來是同一套

> 目標：學生從闖關地圖點進任何一個單元，都認得出「這是同一個網站」——同樣的底紙、同樣的頁首、同樣的課程小卡、同樣的顏色規則。
> 單一來源：`shared/theme.css`（顏色代號與共用元件）。頁面裡**不要**自己寫顏色，一律用代號。

## 一、顏色：四組代號，各有各的用途

| 組別 | 代號 | 用在哪裡 | 規則 |
|---|---|---|---|
| 紙與墨 | `--paper-bg` `--ink` `--ink-soft` `--card` `--line` | 底紙（方格紙）、文字、卡片、框線 | 全站固定 |
| 回饋色 | `--ok` 綠、`--bad` 紅、`--warn` 橘、`--star` 金 | 答對、答錯、提醒、星星 | 全站固定，**不跟單元變**：綠色永遠代表「對／完成」 |
| 單元色 | `--u1` 藍、`--u2` 綠、`--u3` 紫、`--u4` 靛（每色四階：主色、`-bg`、`-soft`、`-line`） | 闖關地圖卡片、頁首小字與底線、關卡卡片上緣、選中狀態、提示框、出題卡 | 依「這學期的第幾個單元」決定，兩學期規則一樣（見下表） |
| 步驟色 | `--s1` 藍、`--s2` 橘、`--s3` 紫、`--s4` 綠 | 課程小卡：單元裡的第 1～4 部分 | 全站同一組；某一課內容本身有主色時（單元一的四課），小卡用那一課的顏色 |

### 單元色對照

| 位置 | 上學期 11601 | 下學期 11602 | 顏色 |
|---|---|---|---|
| 第 1 個單元 | 一 數位時代 | 四 多媒體專題：30 秒廣告 | 🔵 藍 `u1` |
| 第 2 個單元 | 二 進入 Python 的世界 | 五 網路世界 | 🟢 綠 `u2` |
| 第 3 個單元 | 三 系統平臺大冒險 | 六 進階資料處理 | 🟣 紫 `u3` |
| 延伸挑戰 | 5016B 智慧教室守護站 | 5016B 守護站 2.0 | 🟪 靛 `u4` |

**自動套用**：`UI.topbar()` 會依 `config.js` 的 `MODULES`（比對網址：單元的 `href`、`parts` 的 `href`、所在資料夾）找出這一頁屬於哪個單元，
把 `--unit`、`--unit-bg`、`--unit-soft`、`--unit-line` 指到那個單元的 `--uN`。元件只用 `--unit`，所以同一個遊戲引擎放在不同單元，顏色自己會換。
要改某個單元的顏色 → 改 `config.js` 的 `color`；要改整套色調 → 改 `theme.css` 的 `--u1`～`--u4`。

## 二、共用元件（`theme.css`）

| 元件 | class | 說明 |
|---|---|---|
| 頁首 | `.topbar`（`UI.topbar()` 產生） | 左：返回鍵（`← 闖關地圖` 或 `← 單元X`）；中：小字（單元色）＋大標題（圖示＋名稱，下有單元色短底線）；右：學生名牌 |
| 卡片 | `.card`（＋`.tape` 紙膠帶） | 白底、1rem 圓角、細框、淡陰影。每頁第一張卡片貼紙膠帶 |
| 課程小卡 | `.ucards` ＞ `.ucard`（`UNIT.cards()` 或頁面自己產生） | 一個單元分成幾個部分時用：編號、圖示、名稱、一句說明、進度條；目前這張浮起來並標「目前在這裡 👇」。部分頁面上方用精簡版 `.ucards.compact`。**一頁裡的小步驟也用同一套**（1-4 的四個小步驟、廣告工作站五步） |
| 固定小卡 | `UI.stickyNav(nav)` → 外層 `.ucards-ph.stuck` | 捲過課程小卡後，精簡成一排「編號＋圖示＋名稱」固定在畫面上方（手機只剩編號＋圖示），隨時可以切換。`UNIT.cards()` 自動套用；頁面自己產生的小卡要自己呼叫一次 |
| 上一個／下一個 | `.pager`（`UI.pager(el, prev, next)`、`UNIT.pager(el, 單元, 目前部分, 單元首頁)`） | 每一課、每一部分、每一小步驟的結尾都放一組：左「← 上一課」、右「下一課 →」（右邊用單元色）。第一課的上一個、最後一課的下一個回單元首頁；手機上下疊 |
| 關卡卡片 | `.lvcard`（遊戲引擎產生） | 上緣單元色；4 張排 2×2、7～8 張每排 4 張（`UI.gridCols`） |
| 任務清單（Python 單元） | `.lv`（`pyapp.js`） | 右邊要留給程式編輯器，所以用左側清單；規則和關卡卡片一樣：單元色邊條、編號圓牌（2⭐ 以上變綠）、金色星星、鎖住變灰、目前這關浮起；清單上方有總進度條 |
| 關卡結束 | `.pager`（`UI.pager`） | 闖關遊戲、試算表、Python 三種引擎都一樣：中間「🔁 再玩一次」，下面左「← 關卡選單」（Python 是「← 上一關」）、右「下一關 →」；還沒拿到 2⭐ 時右邊顯示「🔒 下一關」；愛心用完時右邊是「再挑戰一次 →」 |
| 按鈕 | `.btn`、`.btn.primary`（墨色）、`.btn.go`（綠，送出／開始）、`.btn.sm` `.btn.big` | 主要動作用墨色，「開始、送出」用綠色 |
| 選項 | `.pick`（`.on` 選中＝單元色、`.right` 綠、`.wrong` 紅） | 遊戲、檢核共用 |
| 提示框 | `.note`（預設單元色）、`.note.ok` `.note.bad` `.note.warn` | |
| 小標籤 | `.chip` | |
| 星星、愛心、進度條 | `.stars` `.hearts` `.bar` | 星星一律金色 |

## 三、頁面骨架（每個單元都一樣）

```
<main class="wrap">                 ← 64rem 寬（Python 編輯器頁用 .wrap-wide）
  <header id="topbar">               ← UI.topbar({ title, kicker, hub, backLabel })
  <nav id="ucards">                  ← 單元有好幾個部分時：課程小卡
  <section class="card pop">＋.tape  ← 單元介紹／遊戲選單
  …內容卡片…
  <nav id="pager">                   ← 結尾：← 上一課／下一課 →
```

| 單元 | 課程小卡（捲動時都固定在上方） | 結尾的上一個／下一個 |
|---|---|---|
| 一 數位時代 | 單元首頁 `digital/index.html` 四張（1-1～1-4）；每一課頁面上方精簡版。1-4 頁內四個小步驟也是小卡 | 每一課：上一課／下一課（1-1 的上一個、1-4 的下一個＝單元首頁）；1-4 的小步驟：上一步／下一步（第 4 步的下一個＝快速檢核） |
| 四 30 秒廣告 | 同一頁的四張卡當分頁：概念闖關 → 看示範 → AI 前導關 → 廣告工作站；工作站五步也是小卡 | 每一部分：上一部分／下一部分（最後接回闖關地圖）；工作站每一步：上一步／下一步 |
| 六 進階資料處理 | 單元首頁 `unit6.html` 三張；三個部分頁面上方精簡版 | 上一課／下一課（頭尾接單元首頁） |
| 5016B（兩學期） | 五節課五張卡 | 上一節／下一節（第 5 節的下一個＝闖關地圖） |

小字（kicker）統一寫法：`單元X · 3上／3下 第 N 章 · 補充說明`；延伸挑戰寫 `延伸挑戰 · 跨章專題 · 五節`。

## 四、單元一（移植頁）怎麼接上

「0 與 1 的藝術」的四課內容區仍用 Tailwind（互動多，重寫風險大），只換掉外框：
- 載入 `theme.css`：方格底紙、字型、登入框、頁首、課程小卡都和其他單元一樣
- 原本的漸層背景、模糊光暈、置中大標題、藥丸導覽列都拿掉，換成 `#topbar`＋`#ucards`（由 `progress-hook.js` 產生）
- `.galaxy-card` 改成全站卡片樣式；課名統一成「1-1 二進位原理」這種課本節次寫法（避免和「單元一」混淆）
- 每一課最後的「課後回顧／快速檢核／同伴討論」改用全站元件（`.card` `.note` `.pick` `.chip`），答對綠框、答錯紅框，和其他單元的遊戲一樣
- 模擬器與小遊戲內部仍保留原本各課的主色（藍、靛、青、玫瑰紅），避免重寫出錯；課程小卡用的也是這四個顏色，所以看得出對應
- 單元首頁 `digital/index.html` 已改寫成全站樣式（不再需要 Tailwind）

## 五、新增頁面時的檢查表

- [ ] 在 `config.js` 的 `MODULES` 有對應（或是某個單元的 `parts`），單元色才會自動套用
- [ ] 用 `UI.topbar()`，小字照統一寫法
- [ ] 顏色只用代號（`var(--unit)`、`var(--ok)`…），不要寫死色碼
- [ ] 單元有好幾個部分：上方課程小卡（會自動固定）、結尾 `UNIT.pager()`；在 `tests/test_nav.mjs` 加上這一頁
- [ ] 手機寬度沒有橫向捲動（`tests/test_mobile.mjs` 加上這一頁）
