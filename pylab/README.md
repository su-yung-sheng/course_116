### 給其他老師的說明（可以直接轉貼）

> 1. 自己先用教師版試玩：`…/pylab/teacher.html`，覺得測資太嚴、題目不清楚，就在那一關按「📮 回報問題」。
> 2. 上課給學生學生版：`…/pylab/`。學生第一次打開要填班級、座號、姓名；一台電腦多人輪流用時，按右上角「換人」。
> 3. 成績只存在那台電腦的瀏覽器（換電腦、清除瀏覽紀錄就沒了）。請學生做完按「🧾 下載成績卡」上傳到你的作業區。
> 4. 成績卡左下角有 🔑 **進度碼**（驗證伺服器簽章）。想確認星星是不是真的：打開教師版 →「🔍 驗證學生成績卡」→ 輸入班級、座號、進度碼。學生改自己電腦的紀錄做不出對的碼。
> 5. 進度存在雲端：電腦教室有還原卡、換電腦都沒關係，每次上課填**一樣的班級、座號**就接著做。姓名打錯按「換人」重打就好，進度不受影響。
> 6. 看全班進度：教師版「📊 學生進度表」，輸入老師密碼（向出題老師索取），可以下載 CSV。

## 🔑 進度碼（伺服器端鎖關、防改星、換電腦還原）

- 12 碼（`XXXX-XXXX-XXXX`，Crockford Base32：沒有 I、L、O、U，抄的時候 O 當 0、I／L 當 1）。前 4 碼是 10 關的星數，後 8 碼是 HMAC 簽章（金鑰＝Apps Script 的指令碼屬性 `SECRET`）。
- 簽章只綁「學期｜班級｜座號」，**不綁姓名**：姓名打錯可以改；同學的碼換了座號就對不上。
- 學生版送出評分（`py`，`mod: 'pylab'`）一定要附進度碼：伺服器確認上一關 ≥ 2⭐ 才評分（否則 `locked`），碼被改過就 `bad-code`。評完回傳新的碼（每關只增不減）。
  所以 F12 改瀏覽器紀錄、直接打 teacher.html 都沒辦法「拿到」後面的星星：畫面開了也送不出分數，教師版評分不會發進度碼。
- `pcv`：驗證進度碼，回傳各關星數（老師驗證成績卡、學生換電腦還原都用它）。
- 程式：`server/53_pylab.js`；測試：`tests/test_server.mjs`（8d）、`tests/test_pylab.mjs`。
- ⚠️ 不要改 `SECRET`：改了以前發的進度碼全部失效。

## ☁️ 雲端存檔（2026-09-29 起）

- 伺服器把每位學生的星數記在出題老師雲端硬碟的試算表 **「course_116 pylab 學生進度」**（工作表「學生進度」：學期、班級、座號、姓名、P1～P10、合計、最後更新、進度碼）。第一次用到時自動建立，ID 記在指令碼屬性 `PYLAB_SHEET_ID`。
- 同一位學生＝學期＋班級＋座號；姓名記最新的一次。⚠️ 目前只給同一所學校用（不同學校的「801 班 7 號」會被當成同一人）。
- 學生登入、每次打開頁面都會同步（`pls`）：雲端紀錄＋這台電腦的進度碼取大的；這台的進度碼被改過就自動換回雲端的。評分（`py`／`pyg`）也照雲端紀錄鎖關，每關星數只增不減。
- 試算表出問題時自動退回只用進度碼（評分結果會提醒學生抄進度碼）。
- 📊 老師密碼：Apps Script 編輯器選函式 **`pylab老師密碼`** → 執行 → 執行記錄會印出密碼和試算表網址（密碼存在指令碼屬性 `PYLAB_TEACHER_KEY`，想換就直接改）。密碼錯每小時最多 30 次。
- 限制：學生身分沒有密碼，知道別人的班級座號就能用他的身分做題（只會讓他的星星變多，不會變少）；成績要當正式分數時，建議搭配課堂觀察或看程式碼。

## 和闖關網站的關係

- 這個資料夾**自成一套**：`api.js`、`pyrunner.js`、`pyworker.js`、`theme.css`、`pyapp.css` 都是 `shared/` 的複本（2026-09-29 複製），改這裡不會影響學生的網站；主系統改了也不會自動跟過來。
- 唯一共用的是**題目**：`levels.js` 由 `node tools/build.mjs` 產生，和學生版同一份。所以依回報調整測資時，改一次 `private/11601/content/python.js`，兩邊一起更新。
- 📚 語法小抄連到闖關網站的 `11601/pyref.html`（另開分頁，只是連結）。
- 學生版過關時，伺服器照樣發收據；如果 Apps Script 有設 `LOG_SHEET_ID`，也會記一列（單元欄是 `pylab`，教師版是 `pylab-teacher`）。這份紀錄在**你的**雲端硬碟，其他老師看不到。

## 📮 回報怎麼收

老師按「送出回報」→ 驗證伺服器 → 寫進你 Google 雲端硬碟裡的試算表 **「course_116 Python 老師回報」**（第一次有人回報時自動建立）。
每一列：時間、狀態（預設「待處理」，處理完自己改）、任務、類別、說明、稱呼、學校／聯絡、星數、通過幾組、沒過的測資、沒達成的結構要求、程式碼。

- 想先找到這份試算表：Apps Script 編輯器上方選函式 **`建立回報試算表`** → 執行 → 下方「執行記錄」會印出網址。
- 送不出去（伺服器還沒更新、沒網路）時，頁面會改成「📋 複製回報內容」，老師可以用 email／LINE 傳。
- 防灌爆：每一欄有長度上限，整個伺服器每小時最多 60 則。

## 依回報調整測資

1. 看試算表的回報（程式碼、沒過的測資都附在裡面）。
2. 改 `private/11601/content/python.js` 的測資／題目／提示。
3. `node tools/build.mjs` → `cd tests && npm test`。
4. 📋 一鍵複製 → 貼到 Apps Script → 管理部署作業 → 新版本（見 `server/README.md`）。
5. 推送網站。試算表那一列的「狀態」改成「已處理」。
